Sarvam AI assistant for NVDA

Purpose: Sarvam AI assistant lets you use the features of the Sarvam AI platform in an easy, accessible manner, directly from NVDA. It brings Sarvam's speech, language and document services to blind and low-vision users through a fully keyboard-driven, screen-reader-friendly interface.

Where to find it: Open the NVDA menu (NVDA+N) → Tools → Sarvam AI. You can also assign your own shortcut to "Opens the Sarvam AI menu" under Preferences → Input Gestures → Sarvam AI. Settings are available from that menu and under NVDA Preferences → Settings → Sarvam AI.

Features

  • Text to Speech – synthesise speech from typed or pasted text, or from an uploaded text, Word or EPUB file; filtered voices by style and gender; save as MP3 or WAV.
  • Speech to Text – transcribe an audio file or your microphone, optionally translating to English; copy or save the transcript.
  • Translation & Transliteration – convert text between English and 10 Indian languages, with selectable styles.
  • Language Detection – identify the language and script of any text.
  • OCR – recognise text from PDFs and images with Sarvam Document Intelligence (23 languages), preserving headings, tables, columns and reading order; save as Markdown, Word or plain text.
  • AI Workforce – one module for AI Assistant, AI Summary, Document Analysis, Content Generation, Question Answering and File Analysis, powered by Sarvam's 105B reasoning model.

About OCR: OCR uses Sarvam's Document Intelligence service, which performs layout analysis so that headings, lists, tables, multi-column text and reading order are preserved rather than flattened. Images are wrapped into a one-page PDF automatically, and multi-page PDFs keep their page order. The previous offline Windows OCR engine was removed because running two engines produced conflicting results.

Getting started

  1. Open NVDA menu → Tools → Sarvam AI → Settings…
  2. Paste your Sarvam API key (from https://dashboard.sarvam.ai).
  3. Press Validate key / Test connection.
  4. If you do not have a key yet, press Generate API key to open the Sarvam developer portal in your browser.
  5. Set your defaults, then press Save.

Menu

All features are under Tools → Sarvam AI: Text to Speech, Speech to Text, Translate, Transliterate, Detect language, OCR, AI Workforce, Settings (API key), Advanced settings, Logs, Check for updates, Help and About.

Keyboard shortcuts

No keyboard shortcut is assigned by default, so nothing clashes with NVDA's own commands. To add your own, go to NVDA → Preferences → Input Gestures → Sarvam AI and assign a key to any command, for example "Opens the Sarvam AI menu", Text to Speech, Speech to Text, Translate, OCR or AI Workforce.

Inside any Sarvam AI window, press Escape to close it — this works even while the cursor is inside a text box.

Text to Speech

Type or paste text into the edit box, or press Upload file to load a text, Word (.docx) or EPUB (.epub) file. Choose a speaking style (News reader, Conversational, Narration, Formal, Expressive) and a gender — the voice list is filtered automatically so only matching voices are offered. Choose a language (Auto detect by default, which also handles mixed-language text) and adjust the Speech speed, Pitch and Volume sliders, each of which announces its purpose and value. Press Convert. Only after the audio is ready do Listen, Save as MP3 and Save as WAV appear.

Speech to Text

Press Choose audio file or Start recording, pick the audio language (or leave it automatic), then press Transcribe. Large audio files are handled for you: anything beyond the real-time limit is processed through Sarvam's batch transcription service and merged into one complete transcript. Tick Translate to English for an English transcript. After transcription finishes, save the result as plain text or a Word document.

Translate, Transliterate, Detect language

Enter or paste text, or press Upload document to load a text, Word, EPUB, PDF or image file (PDFs and images are read with Sarvam OCR first). Choose the Operation — Translation, Transliteration or Language detection — set the languages, and press Go. Text of any length is handled automatically. Save options appear once the result is ready.

AI Workforce

This single module replaces the old separate AI Assistant and AI Summarise windows. When it opens, the cursor is in Ask a question. Press Shift+Tab to reach Upload file, which accepts text, Word, EPUB, PDF, image and audio files (PDFs and images are read with OCR and audio is transcribed automatically). Press Tab from the question box to reach the Response, then Tab again for Task mode (AI Assistant, AI Summary, Document Analysis, General AI Workforce, Content Generation, Question Answering, File Analysis), reasoning effort and the Run button. Ctrl+Enter in the question box also runs the task. When a response is ready you can save it as text, Word or Markdown.

OCR

Press Choose PDF or image, set the Document language (Auto detect by default) and the output structure, then press Perform OCR. The recognised text keeps the document's structure. Once recognition finishes you can save it as Markdown (Sarvam's original structured output, convertible to any format), Word (real headings and tables) or plain text, or send it straight to Translation or the AI Workforce.

Troubleshooting

SymptomCause / fix
"No Sarvam API key set"Enter your key in Settings.
"Authentication failed"The key is wrong; re-check it.
"No credits available"Your account needs credits – add them in the Sarvam dashboard.
"Windows OCR is not available"Install a Windows OCR language pack in Windows Settings.
Nothing happens on the networkCheck your connection, proxy and network timeout in Settings; open Logs for details.

Privacy

Your API key is stored obfuscated in NVDA's configuration. Text, audio and images you process are sent to Sarvam for processing; OCR runs locally in Windows.
